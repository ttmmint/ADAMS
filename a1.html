1. Introduction

In this part, we generate synthetic data for the proposed study. The study investigates whether adding a human demonstration to a text instruction affects the time an embodied AI robot needs to complete a manipulation task.

The independent variable is the instruction condition: - Text-only - Text + demonstration

The dependent variable is task completion time, measured in seconds.

We generate two datasets:

  1. A dataset in which a true effect exists.
  2. A dataset in which the null hypothesis is true.

The effect of the human demonstration is controlled by an adjustable parameter called effect_size.

2. Load packages

# Load the packages needed for data manipulation and visualisation
library(tidyverse)

3. Set seed and Define simulation parameters

# Set a seed to for reproducibility
set.seed(42)

# Total number of robot trials
N <- 100

# Number of trials in each experimental condition
n_per_group <- N / 2

# Mean completion time for the text-only condition, in seconds
mean_text <- 30

# Standard deviation of completion time within each condition, in seconds
sd_completion <- 5

# True effect of adding a human demonstration
# A negative value means that the demonstration is expected to
# reduce completion time
# For example, -3 means that the demonstration reduces the
# population mean completion time by 3 seconds
effect_size <- -3

# Mean completion time in the demonstration condition
mean_demo <- mean_text + effect_size

4.1 Simulate the dataset with a true effect

# Generate completion times for robots receiving the text-only instruction
# rnorm() draws random observations from a normal distribution.
# The distribution has a mean of 30 seconds and an SD of 5 seconds
text_effect <- rnorm(
  n = n_per_group,
  mean = mean_text,
  sd = sd_completion
)

# Generate completion times for robots receiving both the text instruction
# and a human demonstration
# The mean is lower by the specified effect size (-3 seconds)
demo_effect <- rnorm(
  n = n_per_group,
  mean = mean_demo,
  sd = sd_completion
)

# Combine the two groups into one data frame
data_effect <- tibble(
  condition = c(
    rep("Text-only", n_per_group),
    rep("Text + demonstration", n_per_group)
  ),
  completion_time = c(
    text_effect,
    demo_effect
  )
)

# Completion time cannot be negative in reality
# We therefore replace any negative simulated values with zero
data_effect <- data_effect %>%
  mutate(
    completion_time = pmax(completion_time, 0)
  )

5.1 Simulate the dataset under null hypothesis

# For the null dataset, we set the true effect to zero, which means that 
# the population mean completion time is identical in the two conditions
null_effect <- 0

# Calculate the mean completion time for the demonstration condition
# under the null hypothesis
mean_demo_null <- mean_text + null_effect

# Generate completion times for the text-only condition
text_null <- rnorm(
  n = n_per_group,
  mean = mean_text,
  sd = sd_completion
)

# Generate completion times for the demonstration condition
# Since null_effect = 0, both groups have the same population mean

8. Compare the two conditions statistically

# Perform the planned independent-samples two-sided t-test
# on the dataset containing a true effect:
# The test compares mean completion time between the two
# instruction conditions
t_test_effect <- t.test(
  completion_time ~ condition,
  data = data_effect,
  alternative = "two.sided"
)
